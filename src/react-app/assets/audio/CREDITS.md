# SoundKit audio

Files in this directory prefixed `soundkit-` are bundled from [SoundKit](https://github.com/thisuxhq/soundkit), specifically its `low-volume-20db` M4A assets:

- `soundkit-start.m4a` — `buttons-and-navigation/button-1.m4a`
- `soundkit-win.m4a` — `complete-and-success/success-1.m4a`
- `soundkit-timeout.m4a` — `notifications-and-alerts/alert-1.m4a`
